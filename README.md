**UndergroundBaseX** is an advanced, AI-powered geospatial analysis tool designed to identify the most suitable locations for **underground base development** in **Malaysia (Borneo & West Malaysia)**.

Using a hybrid engine of live APIs, static geographic datasets, and NASA/USGS data, it evaluates sites across 12 critical criteria (Elevation, Bedrock Depth, Water Table, Seismic Risk, Geology, Population Density, Coastal Proximity, Infrastructure, Land Availability, Flood Risk, Slope, and Fault Proximity) to produce a comprehensive 5-phase development plan.

## 🌟 Key Features

*   **🔍 Dual-Region Support:** Analyze locations across Sabah, Sarawak (Borneo), and Peninsular Malaysia.
*   **🛰️ Live Data Integration:**
    *   **USGS:** Live seismic activity within 200km.
    *   **Open-Elevation API:** Live topographic data.
    *   **OneGeology (WMS):** Global bedrock geology overlay.
*   **⚖️ Dynamic Scoring & Penalties:** Automatically detects "mission-kill" hazards (e.g., UNESCO protected areas, shallow water tables, high flood risks) and caps the final score accordingly.
*   **🔄 Smart Alternatives Engine:** If a site is blocked or hazardous, the app instantly recommends the best nearby alternatives.
*   **📊 Multi-Site Comparison:** Rank and compare up to 15 sites side-by-side using radar charts and data tables.
*   **📋 5-Phase Development Plan:** Generates a complete engineering and cost breakdown:
    *   *Phase 2: Base Infrastructure (Transport & Utilities)*
    *   *Phase 3: Construction Simulation (Timelines & Resources)*
    *   *Phase 4: Public Engagement (Consultation & Tourism)*
    *   *Phase 5: Global Expansion (Mars Adaptation & Climate Resilience)*
*   **💾 Agent Memory:** Saves past analyses to an SQLite database for future reference.
